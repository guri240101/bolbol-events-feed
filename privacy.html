뽈뽈플랜 · 고객지원 및 개인정보 안내

개인정보 처리방침

시행일: 2026년 9월 27일 · 최종 수정일: 2026년 10월 10일

뽈뽈플랜 운영자 권승진(뽈뽈쀼)은 이용자의 개인정보를 보호하며, 앱에서 처리하는 정보와 삭제 방법을 다음과 같이 안내합니다. 이 방침은 일반 사용자용 뽈뽈플랜 Android 앱과 이 안내 페이지에 적용됩니다.

1. 기기에서 처리하는 여행 정보

여행 지역, 날짜와 시간, 취향, 이동수단, 인원과 예산, 생성·편집한 일정, 저장 여행, 닉네임, 방문 완료 기록, 저장한 맛집·카페 및 알림 설정은 일정 구성과 저장 기능을 위해 이용자의 기기에서 처리됩니다. 현재 일반 사용자 앱은 회원가입을 요구하지 않으며 여행 계획을 운영자 서버에 자동 업로드하지 않습니다. 여행지의 좌표는 장소 자료이며, 기기의 GPS 위치를 수집하는 기능은 사용하지 않습니다. 연락처, 통화 기록, 광고 식별자를 수집하지 않으며 광고·사용자 행동 분석 SDK를 탑재하지 않았습니다.

2. 인터넷 연결과 외부 제공자

최신 장소·행사 정보, 지도, 영상 썸네일을 표시하기 위해 아래 서비스로 요청이 전송됩니다. 요청 과정에서 IP 주소, 요청 시각·경로, 브라우저·기기에서 전송하는 기술 정보 등이 해당 제공자에게 전달될 수 있습니다. 이는 여행 정보 제공과 네트워크 운영·보안 목적으로 처리되며, 이용자의 여행 계획 전체나 입력한 예산을 이 요청에 첨부하지 않습니다.

  • Cloudflare: 운영자의 공개 장소 자료 API 제공. Cloudflare 개인정보 안내
  • GitHub Pages: 공개 행사 자료 및 이 개인정보 처리방침 제공. GitHub는 보안 등을 위해 방문자의 IP 주소를 기록할 수 있습니다. GitHub 개인정보 안내
  • OpenFreeMap: 확대 지도의 벡터 타일·지도 글꼴 제공. 표시 영역과 IP 주소 등 연결 정보가 지도 서버에 전달될 수 있습니다. 제공자 안내
  • OpenStreetMap: 지도 타일 제공. 지도에 표시한 영역에 해당하는 타일 요청이 전송됩니다. OpenStreetMap 개인정보 안내
  • Google/YouTube: 추천 영상의 썸네일 제공(i.ytimg.com). Google 개인정보 안내

외부 제공자는 미국 등 해외 서버를 포함한 인프라를 사용할 수 있습니다. 제공자가 처리하는 기술 로그의 보관 기간과 삭제 절차는 각 제공자의 정책에 따릅니다. 운영자 앱의 공개 자료 조회 API는 일반 이용자의 여행 계획이나 조회 이력을 별도 데이터베이스에 저장하지 않습니다.

3. 파일 공유와 외부 사이트

이용자가 일정 파일 공유를 선택하면 여행 날짜·시간·장소명·주소와 직접 작성한 내용이 파일에 포함됩니다. Android 공유 화면에서 이용자가 선택한 서비스 및 수신자에게 전달되므로, 공유 전 개인 주소나 민감한 내용이 포함돼 있지 않은지 확인해 주세요. 다른 사람에게 이미 전달한 파일은 앱에서 자동 회수할 수 없습니다. 현재 공개 커뮤니티 업로드 및 서버 기반 공동 편집은 제공하지 않습니다.

영상·예약·지도 링크를 누르면 외부 사이트가 열립니다. 해당 사이트에서 입력하는 예약자 정보·결제 정보 등은 그 사이트가 처리하며 각 사이트의 개인정보 처리방침이 적용됩니다. 뽈뽈플랜이 예약 결제 정보를 받는 것은 아닙니다.

4. 알림과 파일 접근

다녀온 여행에 선택한 사진은 기기에서 크기를 줄여 앱 내부 저장소에 보관합니다. 사진·여행 기록은 자동으로 서버에 업로드하지 않습니다. 앱 삭제 시 사라지므로 원본 사진은 별도로 보관하세요.

행사 접수 알림은 이용자가 허용한 경우 기기의 로컬 알림으로 예약됩니다. 알림 표시 권한과 정확한 알람 접근 설정은 Android 설정에서 변경할 수 있습니다. 공유용 파일은 앱의 캐시 공간에 생성하며, 파일 가져오기는 이용자가 선택한 파일을 읽어 처리합니다. 전체 사진첩이나 연락처 접근을 요구하지 않습니다.

5. 보관 기간과 삭제

  • 기기에 저장된 여행과 설정은 해당 항목을 삭제하거나 Android 설정의 앱 저장공간에서 데이터를 삭제할 때까지 보관됩니다. 앱 삭제 시 앱 전용 저장 정보도 삭제됩니다. 다른 위치로 내보낸 파일은 이용자가 따로 삭제해야 합니다.
  • 알림은 앱에서 해제할 수 있으며 기기 설정에서 알림 권한을 끌 수 있습니다.
  • 고객지원 이메일을 보내면 회신 주소와 문의 내용, 이용자가 첨부한 자료를 문의 응대에 이용합니다. 운영자는 문의 처리 완료 후 30일 이내에 해당 문의를 삭제합니다. 법령에 따른 별도 보관 의무가 있는 경우에는 필요한 범위에서 보관합니다.
  • 일반 이용자 계정이 없으므로 별도 회원 탈퇴 절차는 없습니다. 기기 정보 삭제 또는 개인정보 관련 문의는 아래 연락처로 요청할 수 있습니다.

6. 이용자의 권리와 보호 조치

이용자는 운영자가 보유한 자신의 문의 정보에 대해 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 본인 확인에 필요한 최소한의 정보를 확인한 후 처리합니다. 주민등록번호, 비밀번호 또는 결제정보를 문의에 보내지 마세요. 서비스의 온라인 자료 연결에는 HTTPS를 사용하며 관리자 수정 기능은 인증된 관리자에게 제한됩니다.
